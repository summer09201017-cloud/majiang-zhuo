# 🀄 麻將桌(majiang-zhuo)

台灣 16 張麻將,一人 vs 三家電腦。純前端 PWA:**零相依、零建置、零美術檔、零後端**。
144 張牌全程式畫,離線可玩,紀錄只在自己的瀏覽器裡。

**只計台/分,不做籌碼與下注。** 屬個人/家庭懷舊系(同紙牌桌、彈珠檯),不是教會遊戲系列。

## 玩

**線上直接玩:https://majiang-zhuo.pages.dev**(手機加到主畫面就是一個 App)

### 玩起來是什麼樣子

輪到你就點手牌把牌打出去。別人打出你要的牌時,下方會跳出 **吃 / 碰 / 槓 / 胡 / 過** 的大按鈕;
摸到能自摸或能槓時也會跳出來。有人胡了就出結算:台數怎麼算的一條一條列給你看,加上分數與總分。
**⚙** 裡可以切音效、一炮多響、**電腦強度**、這一場打幾局(單局 / 一圈 4 局 / 全將 16 局)、
看 🏆 成績榜、以及 ⛶ 全螢幕。

**打到一半被切走沒關係** —— 回來會接著上次那一局繼續打(存在自己這台裝置裡)。
手機請橫著拿:直向會蓋版提示轉橫,橫向時畫面會鋪滿、手牌也夠大按。

不會打也沒關係:輪到你的時候按 **💡 提示**,它會把建議打的那一張框起來,
並且告訴你「打完還差幾步、接下來等哪些牌、那些牌檯面上還剩幾張」。

### 電腦有多強?

三級,而且是**量出來的**不是喊出來的(`node scripts/balance.mjs`,每級 80 局對三家「普通」):

| 等級 | 胡牌率 | 收場還差幾步 | 平均得分 |
|---|---|---|---|
| 新手 | 8% | 1.91 | −9.1 |
| 普通 | 24% | 0.61 | +2.6 |
| 老手 | 28% | 0.50 | +1.1 |

新手是真的弱(陪小孩玩的那一級)。**老手比普通「快」,但點數上目前打平** —— 誠實講,
這一版沒有振聽/過水規則,「安全牌」的訊號很弱,要讓老手在點數上真的贏還需要更深的工程。

### 台數怎麼算(v1,「最簡單好算」版)

一條原則決定了整張表:**凡是需要知道「你聽的是什麼形狀」的台,一律不採**——
平胡、獨聽、單吊、邊張、嵌張都拿掉了,它們是唯一需要回推聽牌型的東西。
七對子也不採,因為台灣 16 張本來就不適用(那是 13 張玩法)。
所以胡牌型**只有一種**:5 副面子 + 1 對將。

剩下 27 條台每一條都有測試案例釘著,而且有一條檢查在守「表裡每一條都真的被算出來過」。
要加回任何一條:改 `TAI` 表 + 判定 + 補一個 golden case,三處缺一不可。

**一炮多響**:兩家同時胡同一張,兩家都算、放炮的人各付一份(預設開)。
⚙ 裡可以切成「順位優先」—— 只有從放炮者算起逆時針最近的那一家胡。

**結算**:底 10 分 + 每台 5 分。自摸三家各付一份;放炮由放炮者一家付。

## 驗收

```
node scripts/smoke.mjs      # 純邏輯:144 張守恆、種子重現、版面不重疊、整局不破
node scripts/verify-ui.mjs  # 真瀏覽器:真滑鼠點牌、牌面烤好沒、直向有沒有提示轉橫
```

`verify-ui` 需要 playwright(repo 零相依,它會自己去別的 repo 找;找不到就跳過並回 3,
不會靜靜算你通過)。`LIVE_URL=https://…` 可以改驗線上、`SHOTS=<資料夾>` 另存截圖。

## 為什麼是這個架構

- **守恆保險絲**:每一步都驗「牌牆+手牌+副露+牌河+花 ≡ 144」。麻將的 bug 九成是牌憑空多或少,
  而且完全靜默 —— 現場抓到才不必事後考古。
- **種子洗牌**:沒有種子,麻將 bug 無法重現。同一個種子連電腦的決策都一模一樣。
- **判定=畫面**:牌畫在哪、點到哪一張,只有 `tilePos` 一份。
